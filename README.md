# 法鉴题库学习平台

面向山东省司法鉴定人执业能力评估题库的在线练习和模拟考试网站。使用 Python 标准库提供 HTTP 服务，MySQL 保存账号、题库、答题记录和考试成绩；PDF 导入依赖 `pdfplumber`。

## 启动

需要 Python 3.10 或更新版本，以及运行中的 MySQL 服务。项目根目录提供本机 `.env` 配置，默认连接 `127.0.0.1:3306`，使用已有的 `root` 用户和密码 `root`，目标库为 `sifa_learning`。应用会直接使用该账号建库并运行迁移，不会提示输入数据库密码，也不会创建其他 MySQL 用户。

部署到其他平台时，复制 `.env.example` 为 `.env`，再按目标环境修改主机、端口、MySQL 用户、密码和数据库名。`.env` 已加入忽略列表，不会提交到版本库；运行环境变量也可以覆盖 `.env` 中的值。

安装依赖并应用迁移：

```powershell
python -m pip install -r requirements.txt
python app.py db-upgrade
python app.py serve
```

`db-upgrade` 会自动创建项目数据库并按顺序执行 `migrations/` 中尚未应用的迁移；每次启动也会检查并应用新迁移。迁移版本记录在 `schema_migrations` 表。初始迁移为所有业务表和字段添加了中文注释。服务首次启动时，若题库为空，会按 PDF 原有题型顺序和题号导入项目根目录的 `题库（电子版）.pdf`。当前 PDF 预期为 1,711 题：单项选择 433、不定项选择 500、判断 504、填空 274。导入遇到题量或答案结构异常时会报错停止，不会静默导入不完整题库。

创建首个管理员：

```powershell
python app.py create-admin --username admin
```

命令会交互式要求设置管理员显示姓名和密码。之后打开 <http://127.0.0.1:18080> 登录。学生账号由管理员在“学生账号”页面创建，也可按页面提示使用 CSV 批量导入。

默认网站地址为 <http://127.0.0.1:18080>。可用参数：`python app.py serve --host 127.0.0.1 --port 18080`。若需让局域网其他设备访问，启动时指定 `--host 0.0.0.0`，并确保网络防火墙规则符合使用环境。HTTPS 反向代理场景可设置 `SIFA_COOKIE_SECURE=1`。

## 服务日志

服务启动后，访问日志会显示在运行窗口，并写入 `instance/logs/sifa.log`。日志包含请求路径、响应状态码以及未处理异常的完整堆栈；文件达到 5 MB 后自动轮转，最多保留 5 个历史文件。接口返回 500 时，可查看运行窗口中的异常堆栈或打开该日志文件定位错误。

## 模拟考试参数

公开资料检索未找到能核实为当前山东省司法鉴定人执业能力评估的考试时长、题量分布和评分细则，因此初始模板使用可编辑示例：120 分钟、100 题（单选 25、不定项 25、判断 30、填空 20），每题 1 分，答错扣分为 0。管理员可在“考试参数”中按题型修改题量、每题分值和答错扣分，并设置不定项选择题部分得分和填空题按空给分规则。错答扣分仅用于未获得部分分的错误作答，空题不扣分；部分得分和答错扣分不会重复计算。管理员可记录正式规则来源。只有填写来源并勾选已核验后，系统才会向学生标记为正式规则已核验。

每次考试按题型题量随机抽题并打乱整卷题序。考试开始后使用该场考试保存的参数快照；作答自动保存，超时自动交卷，交卷后展示逐题结果。

## 数据与备份

MySQL 连接配置由 `.env` 中的 `SIFA_DB_HOST`、`SIFA_DB_PORT`、`SIFA_DB_USER`、`SIFA_DB_PASSWORD` 和 `SIFA_DB_NAME` 控制。建议定期使用 `mysqldump -h 127.0.0.1 -P 3306 -u root -p sifa_learning > sifa_backup.sql` 备份数据库，并备份原始 PDF。迁移部署时先安装依赖、更新目标环境的 `.env`，再运行 `python app.py db-upgrade`。学生密码使用带随机盐的 PBKDF2 哈希保存。

## 验证

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

自动化测试会使用临时 SQLite 数据库隔离测试数据；网站运行环境默认始终使用 MySQL。
